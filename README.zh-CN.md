# GC 艺术史粒子地球玩法

[English](README.md)

把已有的粒子地球或艺术史地图，变成一个适合手机传播的完整体验：先玩地球，再放入自己的瞬间，生成私人光点和数字展厅；只有用户主动申请公开后才进入审核与发布。

![ART LOOKS BACK 粒子地球玩法](assets/particle-earth-play.jpg)

## 这个 Skill 能做什么

- 保留粒子地球作为第一屏，三秒内即可划动或滚动时间。
- 让用户上传一张自己的照片或作品，先获得私人预览。
- 自动保持图片比例、缩放尺寸并转换成网页格式，不要求用户手动裁图。
- 把私人瞬间变成一枚个人光点；点击光点进入个人 3D 数字展厅。
- 私人保存与公开发布彻底分开；只有主动申请公开才启动服务器审核。
- 为通过审核的光点生成分享链接、静态海报或四秒竖屏传播视频。
- 检查手机触控、低性能模式、减少动态效果和真实发布边界。

## 最重要的产品路径

```text
粒子地球 → 第一次划动 → 上传一个瞬间 → 自动整理图片 → 私人光点
→ 点击自己的光点 → 个人 3D 展厅 → 主动申请公开 → 审核 → 公共光点与分享
```

不要用上传表单或展厅替代粒子地球。展厅必须是用户创造光点之后得到的第二层空间。

直接复制：

```text
使用 $gc-art-history-particle-play，保留现有粒子地球作为第一屏，让用户先划动地球，再上传一个私人瞬间。自动整理图片并生成个人光点；点击自己的光点后进入个人 3D 展厅。私人保存不触发审核，只有用户主动申请公开时才审核。
```

```text
使用 $gc-art-history-particle-play 审核这个粒子地球体验，告诉我为什么用户只会看、不会玩、不会上传或不会分享，并给出最小修改方案。
```

## 小白怎么玩

1. 打开粒子地球，先横向划动；也可以纵向滚动时间。
2. 地球响应后，点击“放入我的第一个瞬间”。
3. 只选一张主体清楚的 JPG、PNG 或 WebP 图片，单张不超过 8 MB。
4. 系统自动保持比例、把最长边缩放到 1600 像素以内并转换网页格式。
5. 写一个短标题；地点、年份和一句话可以不填。
6. 保存后回到地球，点击刚刚生成的彩色光点。
7. 进入自己的 3D 展厅，滚动或拖动浏览，点击作品查看详情。
8. 只有确实想公开时，才点击独立的“申请公开发布”。

更完整的新手文案见：[中文小白玩法](references/beginner-playbook.zh-CN.md)。

## 个人展厅适配器

[`templates/personal-gallery`](templates/personal-gallery/README.zh-CN.md) 提供：

- 私人单图上传组件；
- 自动图片整理函数；
- 可挂载最多 12 件作品的 Three.js 悬挂式展厅；
- 手机触控、滚轮/拖动、键盘和减少动态效果支持。

它不是独立网站，也不包含 ART LOOKS BACK 的博物馆藏品或公共用户内容。宿主产品必须继续使用自己原有的粒子地球。

## 四种工作模式

- `strategy`：设计最小传播闭环、安全边界和指标。
- `prompt`：为其他设计或开发工具生成实现说明。
- `implementation`：检查真实项目，进行局部修改并验证页面。
- `audit`：诊断用户为什么只看不玩、只玩不传或无法分享。

## 安全边界

用户可以立刻获得私人预览和本地海报，但这不等于同意公开。公共光点、公共媒体地址、公开下载视频和分享链接，都必须在用户主动申请公开并通过服务器审核后生成。待审、拒绝或私人内容不得出现在公共查询中。

本 Skill 提供产品与实现指导，不构成法律意见。正式上线前仍需核对当前审核服务能力和适用法规。
