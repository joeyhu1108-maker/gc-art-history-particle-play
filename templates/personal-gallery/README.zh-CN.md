# 个人 3D 展厅适配器

[English](README.md)

这个适配器把已有粒子地球连接到私人 Three.js 数字展厅。它不提供替代地球，也不包含博物馆藏品、ART LOOKS BACK 作品或公共用户内容。

> 不要把这个目录当作独立第一屏运行。用户必须先看到并划动宿主产品原有的粒子地球；地球响应后才能上传，用户点击自己创建的光点后才能进入展厅。

## 包含内容

- `HangingGallery.tsx`：最多展示 12 件图片作品的通用悬挂式 3D 展厅；
- `PersonalMomentUpload.tsx`：第一次地球交互后显示的私人单图上传组件；
- `preparePersonalMomentImage.ts`：保持比例的自动缩放和网页格式转换；
- 桌面、触控、手机和减少动态效果样式。

## 宿主必须负责的流程

```text
粒子地球 → 地球产生响应 → 上传 → 地球出现私人光点
→ 点击光点 → 个人 3D 展厅 → 瞬间详情
```

适配器只负责上传、图片整理和展厅。不要用普通球体替换产品已有的粒子地球，也不要绕过地球直接打开展厅。

## 安装到现有项目

把这个目录复制到 React + TypeScript 项目，然后安装 Three.js：

```bash
npm install three
```

宿主应在用户第一次划动地球之后才显示 `PersonalMomentUpload`。收到图片后调用 `preparePersonalMomentImage` 自动整理，再创建私人光点。只有用户点击该光点时才挂载 `HangingGallery`。

## 图片整理规则

- 仅接受 JPG、PNG 和 WebP；
- 单张不超过 8 MB；
- 保持原图宽高比；
- 最长边不超过 1600 像素；
- PNG 保持 PNG，其他支持格式输出为 WebP；
- 返回整理后的宽高和私人预览地址。

## 隐私与公开边界

浏览器内的 `URL.createObjectURL` 只适合即时私人预览，刷新页面后可能失效。需要长期保存时，接入私人存储服务。

“保存到我的展厅”不等于同意公开。正式公开应使用独立流程：

```text
私人预览 → 主动申请公开 → 服务器审核 → 审核通过 → 公共光点与分享链接
```

正式上线前还需要隔离存储、服务端图片与文字审核、重新编码与元数据清理、频率限制、举报和申诉。待审或拒绝内容不能获得公共地址。
