# Beginner Playbook

Use this guide when the visitor is not a designer, developer, or experienced AI creator.

## The first 30 seconds

1. Open on the particle Earth. Do not open on an upload form or gallery.
2. Say: `先横向划一下这颗地球，也可以滚动时间。`
3. After the Earth responds, show: `放入我的第一个瞬间`.
4. Let the visitor choose exactly one image and one short title.
5. Return to the Earth with one new personal light point.
6. Say: `点你刚创造的亮点，就会进入自己的数字展厅。`

## The visitor does not need to prepare the image

The product should do the mechanical preparation:

- accept JPG, PNG, or WebP up to 8 MB;
- preserve the original aspect ratio;
- reduce the longest edge to at most 1600 px;
- redraw the image into a clean browser canvas and export a web-ready PNG or WebP;
- show the prepared dimensions before saving;
- keep the first result private on the visitor's device or account.

Ask the visitor for only this:

- choose one image with a clear main subject;
- avoid a collage of many small images for the first attempt;
- avoid screenshots whose meaning depends on tiny unreadable text;
- if the upload fails, confirm the file type and 8 MB limit before asking them to edit it.

## Recommended helper copy

```text
不用提前裁图。系统会自动保留比例、整理尺寸并转成适合网页的格式。
第一次只选一张主体清楚的照片或作品就够了。
```

## What happens after upload

`private image -> prepared private preview -> personal light point -> click point -> personal 3D gallery`

Saving a private moment must not request public publishing. Public display is a separate explicit action:

`request public publishing -> server moderation -> approved -> public point/share link`

## Do not make beginners do these things

- install dependencies before they can understand the experience;
- crop, resize, convert, or strip metadata manually;
- choose a color system, gallery layout, or art-history category;
- understand moderation before receiving a private preview;
- search a public globe full of other people's points before creating their own.
