# 小白上手指南

这份指南用于第一次接触粒子地球、不懂设计、不会裁图，也不知道“数字展厅”是什么的用户。

## 前 30 秒

1. 第一屏直接显示粒子地球，不要先显示上传表单或展厅。
2. 提示：`先横向划一下这颗地球，也可以滚动时间。`
3. 地球产生可见响应后，再显示：`放入我的第一个瞬间`。
4. 用户只需要选择一张图片并写一个短标题。
5. 保存后回到地球，让一枚新的个人光点清楚出现。
6. 提示：`点你刚创造的亮点，就会进入自己的数字展厅。`

## 用户不需要自己整理图片

产品负责完成：

- 接受不超过 8 MB 的 JPG、PNG 或 WebP；
- 保持原图比例；
- 把最长边缩放到 1600 像素以内；
- 通过浏览器画布重新输出为网页可用的 PNG 或 WebP；
- 保存前显示整理后的尺寸；
- 第一次生成的结果只保存在用户设备或私人账户中。

只要求用户：

- 第一次选择一张主体清楚的图片；
- 暂时不要选由很多小图组成的拼贴；
- 暂时不要选必须放大才能读清小字的截图；
- 上传失败时先检查格式和 8 MB 限制，不要先让用户学习修图软件。

## 推荐界面文案

```text
不用提前裁图。系统会自动保留比例、整理尺寸并转成适合网页的格式。
第一次只选一张主体清楚的照片或作品就够了。
```

## 上传之后发生什么

```text
私人图片 → 自动整理 → 私人预览 → 个人光点 → 点击光点 → 个人 3D 展厅
```

保存私人瞬间不能自动申请公开。公开必须是另一条明确路径：

```text
主动申请公开 → 服务器审核 → 审核通过 → 公共光点与分享链接
```

## 不要要求小白做这些事情

- 安装依赖后才能理解产品；
- 手动裁图、缩放、转格式或清理元数据；
- 选择配色系统、展厅模板或艺术史分类；
- 在得到私人预览前先理解审核规则；
- 先在充满他人观点的公共地球中搜索，再创造自己的瞬间。
